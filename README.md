# 那条没发出去的消息开发源码

故事对话版 v0.4，2026-10-15。

双击index.html，用现代Edge或Chrome浏览器打开。主线、图案、动画和输入均离线运行；参考资料外链需要网络。

## 修改与构建

- src/pages.json：15页情节、独白、知识卡和交互说明。
- src/sources.json：官方来源与核对信息。
- src/app.js：状态机、分支、动画、科普面板和本地输入。
- src/visuals.js：原创可编辑SVG校园图案。
- src/style.css、src/v03.css 与 src/v04.css：校园配色、场景布局、字体分工与动画。
- src/fonts.css：内嵌两款字体的WOFF2字库。
- src/fonts/：字体子集、覆盖信息、来源与OFL许可证。
- src/reading.js：逐句逐字播放与取消。
- src/diagrams.js：三张原创科普图解。
- build.mjs：将上述源码打包回自包含index.html。

使用Node.js运行 `node build.mjs`。HTML重建无第三方包或安装步骤。字体子集已生成；改文案超出字库时后备字体仍可显示，重新制作字库时需使用获许可的原始字体。请先保留一份index.html；生成脚本会更新其内嵌样式和数据。

## 隐私与内容

用户输入只在当前页面内存保留，无上传、AI分析、持久存储、追踪或真实发送。不要添加与可见隐私说明冲突的统计或接口。请用虚构文字测试。

故事、对话与图案由本项目创作，部分制作使用AI辅助。医学内容有来源核对，但仍待专业教师审核。不是疾病筛查或治疗工具。
